# Sprint 5: Class Inheritance & Polymorphism (Weeks 9 & 10)

**Theme:** Advanced Object-Oriented Programming: Subclasses, super references, and polymorphism (AP CSA Unit 3 equivalent - Class Inheritance).

---

## 📋 Iteration Checklist

### Week 9: Inheritance hierarchies & Subclasses
*   [x] **1. Subclass Declaring & Super Reference**
    *   Design lessons showing subclassing syntax (`class Child(Parent):`) and accessing parent constructors using the `super()` method.
*   [x] **2. Method Overriding**
    *   Build exercises that demonstrate replacing parent behaviors with child implementations in a hierarchy.

### Week 10: Polymorphism in Practice
*   [x] **3. Polymorphic Collections**
    *   Implement assignments where arrays/lists contain different objects inheriting from a common base class, invoking overridden behaviors dynamically.
*   [x] **4. Module 5 Lessons & Autograding Tests**
    *   Build 5 core learning exercises (with detailed curriculum helper explanations in prompts) and 1 summative unit assessment:
        *   `simple_inheritance`: Creating a child class inheriting parent variables.
        *   `super_call`: Invoking the parent's `__init__` constructor using `super()`.
        *   `method_override`: Overriding parent method behavior in a subclass.
        *   `polymorphic_list`: Traversing a mixed list of parent/child objects and executing a shared method.
        *   `isinstance_checks`: Using `isinstance()` to check object inheritance relationships dynamically.
        *   `unit5_assessment: Summative Assessment implementing subclasses, method overriding, super calls, and polymorphic object collections.`
