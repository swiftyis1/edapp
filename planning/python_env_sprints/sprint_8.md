# Sprint 8: Searching, Sorting, & Recursion (Weeks 15 & 16)

**Theme:** Core algorithms (linear/binary search, selection/insertion sort), recursive calls, and stack traces (AP CSA equivalent).

## 📋 Iteration Checklist

### Week 15: Search & Sort Algorithms
*   [x] **1. Linear vs. Binary Search**

### Week 16: Recursion & Advanced Sorting
*   [x] **3. Recursive Functions**
    *   Design lessons explaining recursion, base cases, call stacks, and the danger of infinite recursion (causing recursion limit crashes).
*   [x] **4. Module 8 & 9 Lessons & Autograding Tests**
    *   Build 5 core learning exercises (with detailed curriculum helper explanations in prompts) and 1 summative unit assessment:

        *   `recursive_factorial`: Writing a recursive function with base case checks.
        *   `recursive_fibonacci`: Writing a recursive Fibonacci function.
        *   `unit8_assessment`: Summative Assessment combining binary search, custom sorting, and recursive base-case calculations.
